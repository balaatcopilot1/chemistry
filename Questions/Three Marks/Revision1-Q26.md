Chapter: Amines

26. Complete the following:
(i) C₆H₅NH₂ + CHCl₃ + alc.KOH →
(ii) C₆H₅N₂Cl + H₃PO₂ + H₂O →
(iii) C₆H₅NH₂ + H₂SO₄ (conc.) →

## Answer

(i) Carbylamine Reaction:
C₆H₅NH₂(l) + CHCl₃(l) + 3 KOH(alc) --[heat]--> C₆H₅NC(l) + 3 KCl(s) + 3 H₂O(l)
Product: Phenyl isocyanide

(ii) Reduction of Diazonium Salt:
C₆H₅N₂Cl(aq) + H₃PO₂(aq) + H₂O(l) --[Cu⁺]--> C₆H₆(l) + N₂(g) + H₃PO₃(aq) + HCl(aq)
Product: Benzene

(iii) Sulphonation of Aniline:
C₆H₅NH₂(l) + H₂SO₄(conc) → C₆H₅NH₃⁺HSO₄⁻ --[453-473 K]--> 4-NH₂–C₆H₄–SO₃H(s) ⇌ ⁺H₃N–C₆H₄–SO₃⁻
Product: Sulfanilic acid (Zwitterion form)
