11. For a reaction 3A → 2B, the rate of reaction + d[B] / dt is equal to :

- A) – 3 / 2 d[A] / dt
- B) – 2 / 3 d[A] / dt
- C) – 1 / 3 d[A] / dt
- D) + 2d[A] / dt

## Answer

**B) – 2 / 3 d[A] / dt**
From reaction stoichiometry, Rate = -1/3 d[A]/dt = +1/2 d[B]/dt, which yields +d[B]/dt = -2/3 d[A]/dt.
